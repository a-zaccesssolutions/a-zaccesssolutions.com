A-Z Access Solutions website upload guide
========================================

This folder is ready to upload to GitHub and connect to Netlify.

What to upload
--------------
Upload the contents of this folder as the root of the GitHub repository.
index.html must sit at the root beside services.html, about.html, contact.html, and the assets folder.

GitHub
------
1. Create a new GitHub repository.
2. Upload everything in this folder to the root of the repository.
3. Commit the files.

Netlify from GitHub
-------------------
1. In Netlify, choose Add new site, then Import an existing project.
2. Connect the GitHub repository.
3. Build settings:
   - Build command: leave blank
   - Publish directory: .
4. Deploy the site.

Netlify drag and drop
---------------------
You can also drag this whole folder into Netlify's manual deploy area.

Important
---------
- Do not upload the parent outputs folder.
- Do not upload only the assets folder.
- The testimonials page is intentionally not included in this launch folder.
